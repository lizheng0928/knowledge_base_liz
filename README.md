## 文件元数据

每个 Markdown 文件顶部包含 HTML 注释形式的 Library 元数据：

```html
<!-- Library File ID: 2112097994768781312 -->
<!-- Original File: WPP Media China Travel and Expense Policy.docx -->
<!-- Original Type: DOCX -->
<!-- Library Path: /Root/政策问答知识库/政策知识库问答机器人/Travel and Expense/WPP Media China Travel and Expense Policy.docx -->
```

| 字段 | 说明 |
|---|---|
| Library File ID | 文件在 WPP Media China Library 中的唯一标识 |
| Original File | Library 中的原始文件名 |
| Original Type | 原始文件格式（DOCX / PDF / XLSX / PPTX / OFT） |
| Library Path | Library 中的完整路径 |
