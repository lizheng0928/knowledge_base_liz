## 价格政策

|  | 填表说明： |
| --- | --- |
|  | 1、请贵司基于2026年预估的市场情况，在下表中做出承诺，报价有效期为2026年1月1日-12月31日 |
|  | 2、我司不接受中标代理商再通过其它代理商或中间商与媒体进行合作 |
|  | 3、错漏播规则：错一补一，漏一补一 |
|  | 4、下表中不允许留空或者添加备注，如有，则会依据当前所有竞标代理商的最差价格再下浮30%作为贵司的报价进行评估 |
|  | 例：如果贵司返点添加备注，当前其它竞标者最差返点报价为6%，则贵司的返点会以6%*(1-30%)=4.2%来进行评估 |
|  | 5、返点结算周期为季度结算，每一季度末会依据上一季度的投放量在本季度进行结算 |
|  | 6、如实际购买执行内容超出本次竞标承诺媒体范围，则我司有权在实际执行过程中另行召集供应商竞价，包括但不仅限于IP内容项目等 |
