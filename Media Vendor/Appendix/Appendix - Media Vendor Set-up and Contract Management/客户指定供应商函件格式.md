## Slide 1

### 推荐客户指定供应商函件格式

尊敬的客户代表：

根据贵司的指定要求， [供应商公司全称] 被指定为 [活动名称] (,或从 [ ] 至 [ ]这段时间内)的[媒体名称]的媒体供应商。

请回复此封邮件来确认您的指定。

Yours,

[SP姓名]

**备注: 此邮件要求发给客户的两名代表且必须获得客户两名代表的书面批准（电子邮件可以）。两名代表必须分别来自以下表格中的不同列：

| 客户代表 1 | 客户代表 2 |
| --- | --- |
| 中国 / 区域 / 全球媒介 / 市场部联系人 | 中国 / 区域 / 全球高级财务代表 |
| 中国 / 区域 / 全球媒介 / 市场部主管 | 中国 / 区域 / 全球高级采购代表 |
|  | 中国 / 区域合规 / 风险与控制 / 法务主管 |

## Slide 2

### Recommended format of client appointment of media vendor

Dear client representative:

According to your appointment, [vendor name] is appointed as a media vendor of [media name] of [campaign name] (,or for the period from [ ] to [ ]).

Please confirm your vendor appointment by returning this email.

Yours,

[SP name]

**Comments: this mail is required to send to two representatives of the client. And written approval must be obtained (email is sufficient) from two representatives of the client. There must be one representative from each of the columns in the table below:

| Client Representative 1 | Client Representative 2 |
| --- | --- |
| Local / Regional / Global media / marketing contact | Local / Regional / Global senior finance representative |
| Local / Regional / Global media  / marketing lead | Local / Regional / Global senior procurement representative |
|  | Local / Regional compliance / risk & controls / legal lead |
